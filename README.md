# PRO/PEDEVTIKA — интерактивный тренажёр по пропедевтике

Однофайловый учебный сайт на основе предоставленного PDF.

## Публикация
GitHub Actions запускает публикацию автоматически при каждом push в `main`. После успешного запуска ссылка на сайт будет доступна в **Settings → Pages** и в результате workflow **Deploy propedeutics trainer to GitHub Pages**.

## Обновление
Замените `index.html` и отправьте изменения в `main`. GitHub Actions опубликует новую версию автоматически.

## Функции
- Тесты с одним или несколькими правильными ответами.
- Задания «Установите соответствие» с выпадающими списками.
- Поиск, список вопросов, случайный вопрос и карточки для повторения.
- Сохранение прогресса в браузере.
